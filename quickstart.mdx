This guide walks you through the minimum steps to go from a fresh clone to a fully running MyLights instance: database, backend API, and frontend dev server.

## Prerequisites

Before you start, make sure you have the following installed:

- **[XAMPP](https://www.apachefriends.org/)** — provides Apache and MySQL/MariaDB locally
- **[Node.js 18+](https://nodejs.org/)** — required to run the Next.js frontend (`node --version` to check)
- **[Git](https://git-scm.com/)** — to clone the repository

## Installation

<Steps>

<Step title="Clone the repository">

```bash
git clone https://github.com/HardBoss07/m106-media-project.git
cd m106-media-project
```

</Step>

<Step title="Set up the database">

1. Open the **XAMPP Control Panel** and start the **MySQL** module.
2. Navigate to `http://localhost/phpmyadmin` in your browser.
3. Click **New** in the left sidebar and create a database named `mylights`.
4. Select the `mylights` database, go to the **Import** tab, and import `db/main.sql`.

<Note>
The `db/main.sql` file creates the full schema: `media`, `category`, `media_type`, `media_category`, `users`, and `roles` tables. Import `db/mock_data.sql` as a second import step if you want pre-populated sample media, categories, and user accounts to explore the UI without adding your own files first.
</Note>

</Step>

<Step title="Configure and start the backend">

1. In the **XAMPP Control Panel**, start the **Apache** module.
2. Copy the contents of the `backend/` folder into your XAMPP `htdocs` directory:

<CodeGroup>

```bash Windows
xcopy /E /I backend C:\xampp\htdocs\mylights-api
```

```bash macOS / Linux
cp -r backend/ /opt/lampp/htdocs/mylights-api/
```

</CodeGroup>

3. Open `backend/config/db.php` and verify the credentials match your MySQL setup:

```php backend/config/db.php
<?php
$host = 'localhost';
$db   = 'mylights';
$user = 'root';      // change if you set a MySQL password
$pass = '';          // change if you set a MySQL password
$port = 3306;
```

<Tip>
XAMPP's default MySQL username is `root` with no password. If you changed these during setup, update `db.php` accordingly.
</Tip>

</Step>

<Step title="Install frontend dependencies">

```bash
cd frontend
npm install
```

</Step>

<Step title="Start the frontend dev server">

```bash
npm run dev
```

The dev server starts on port 4000. Open `http://localhost:4000` in your browser.

<Warning>
The frontend connects to the backend at `http://localhost/backend/api`. Apache must be running in XAMPP before you open the app, or all API calls will fail and the media grid will appear empty.
</Warning>

</Step>

</Steps>

## Verify the setup

Once both servers are running, confirm everything is wired up correctly:

| Check | Expected result |
|---|---|
| `http://localhost:4000` | MyLights frontend loads |
| `http://localhost/mylights-api/api/media` | Returns a JSON array of media records |
| `http://localhost/phpmyadmin` | `mylights` database visible with populated tables |

If you imported `db/mock_data.sql`, the media grid on the home page should display sample entries immediately.
