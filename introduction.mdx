## What is MyLights?

MyLights is an open-source, self-hosted media browser built on a modern web stack. It gives you a clean, responsive interface to browse, search, and play your local media collection — images, videos, and audio files — all served from your own machine.

Originally conceived as an Electron desktop app, MyLights was migrated to **Next.js** to take advantage of modern web APIs, server-side rendering, and improved performance. The backend is a lightweight **PHP 8** REST API served by Apache (via XAMPP), and media metadata is stored in a **MySQL/MariaDB** database.

## Architecture overview

MyLights follows a classic client-server architecture optimized for local (self-hosted) operation:

```
Browser (Next.js frontend)
        │
        │  HTTP / REST
        ▼
Apache via XAMPP (PHP backend)
        │
        │  MySQLi
        ▼
MySQL / MariaDB database
```

| Layer | Technology | Details |
|---|---|---|
| Frontend | Next.js 16, TypeScript, Tailwind CSS | App Router, React 19, runs on port 4000 |
| Backend | PHP 8, Apache (XAMPP) | REST API in `/backend/api/` |
| Database | MySQL / MariaDB | Schema in `db/main.sql`, port 3306 |

## Tech stack

- **Frontend**: [Next.js](https://nextjs.org) 16 with the App Router, TypeScript, Tailwind CSS 4
- **UI components**: [Lucide React](https://lucide.dev) icons, custom CSS
- **Video processing**: [@ffmpeg/ffmpeg](https://ffmpegwasm.netlify.app) for browser-side thumbnail extraction
- **Backend**: PHP 8.x with MySQLi, served by Apache
- **Database**: MySQL / MariaDB with a normalized schema (media, categories, users, roles)
- **Deployment**: XAMPP (Windows/Linux/macOS), with PowerShell and bash deploy scripts
